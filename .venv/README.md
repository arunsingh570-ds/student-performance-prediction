# Student Performance Prediction

A Machine Learning web application that predicts student performance using study habits, attendance, sleep hours, social media usage, and other lifestyle factors.

## Features

- Data preprocessing and analysis
- Machine Learning model training
- Student performance prediction
- Flask web application
- Clean and simple UI

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- HTML/CSS

## How to Run

```bash
git clone https://github.com/arunsingh570-ds/student-performance-prediction.git
cd student-performance-prediction
pip install -r requirements.txt
python app.py
